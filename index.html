这套能力不挑领域
— HR 只是第一个跑通的验证场，方法本身与行业无关

业务链路

主线是一条完整的 B 端业务链路（洞察 → 获取 → 筛选 → 甄别 → 留存），我用招聘业务作为样本把它整条跑通了。选这个样本，是因为它链路足够长、数据足够非标、对准确率足够苛刻——能在这里立住的方法，换到别的业务域同样立得住。另附独立开发与学术研究两条个人线。每张卡都保留了完整迭代日志：从 V1 的不足到当前版本，每次改动都写着当时发现的问题。

索书区 D · About

关于我

211 本 + 985 硕士，医学图书情报（信息检索 / 知识图谱）出身——第一份手艺是给信息编目：把散落的文献、政策、问卷，整理成可检索、可复核的结构。这套训练决定了我做 AI 产品的方式：先定证据标准，再谈结论。

博世（全球头部汽车技术企业）AI 产品实习：独立负责满意度分析 Chatbot 从需求定义到落地上线的全流程，把原本靠人工抽样的问卷分析换成全量结构化输出。金斯瑞生物科技（生物医药领域头部企业）主导企业级智能体矩阵从 0 到 1，贯通 B 端招聘业务的完整链路；C 端独立定义并实现一款桌面 AI 陪伴助手，意图识别做到 90%+。

医学训练给我对证据的要求，情报学给我编目的方法，产品让方法长出业务价值，AI Coding 让我不必等开发排期。任何需要「非标信息处理 + 可信 AI 输出」的业务，都可以平移这套架构。
